Hikvision Toolkit

GS Electrical · offline. Reset codes, site prep & remote-access reference in one file.

Authorised use only · runs fully offline For devices you own or are contracted to service, with the owner's permission. Reset codes are applied on site via the SADP tool on the device's local network; the camera's clock date must match. A lost password can't be reset remotely. Nothing here is sent anywhere.

Date must match the camera's own clock (SADP Start Time after a power-cycle), not today.

—
Steps
  1. Find the device in Hikvision SADP on the local network.
  2. Read its serial and Start Time date into the fields above.
  3. Copy the code; paste into SADP's Serial code / Security code box and apply.
  4. Default password after reset is usually 123456789abc — change it immediately.

A — Hik-Connect (recommended default)

Easiest · no router changes

Cloud relay (P2P): the device dials out, so you reach it without opening ports.

  1. Configuration → Network → Advanced → Platform Access, tick Enable, platform Hik-Connect, set a verification code.
  2. Confirm the device has internet (gateway/DNS correct).
  3. Add it to your installer account (Hik-Connect / iVMS-4200 / Hik-Partner Pro) by serial + verification code — or have the customer Share it to you.
  4. From home, open Hik-Connect or iVMS-4200 — device is there to view & configure.

+ No exposed ports. + Survives changing IPs. + Customer can revoke anytime.

− Relies on Hik cloud. − Deep settings easier over full web UI (use VPN).

B — VPN into the site network

Most secure direct access

If the router supports VPN (WireGuard/OpenVPN/IPsec), set it up once; join their LAN from home and reach the camera's full web UI as if on site.

  1. Enable the router's VPN server (or add a VPN box); create your client profile.
  2. Connect, then browse the device's local IP (e.g. https://192.168.1.64) or add by LAN IP in iVMS-4200.

+ Nothing camera-facing exposed. + Full access. + One tunnel covers all devices.

− Needs a capable router / VPN device. − A little more first-time setup.

C — DDNS + port forwarding

Works, but exposes the device — harden it

DDNS tracks the changing public IP; router forwards a port to the device. Puts the device on the public internet, so only with the hardening below.

  1. Set up DDNS (router's, or device Network → DDNS).
  2. Forward a non-default external port to the device's HTTPS port; HTTPS only.
  3. Reach it at https://yourname.ddns.net:PORT.

Strong unique admin password · latest firmware · HTTPS only · non-default ports · disable unused services (UPnP, old ONVIF, Telnet/SSH) · lock the forward to your IP if possible. Prefer A or B.

If the password is lost (not remote)

Remote password reset is deliberately blocked. You need someone on the local network with SADP: a site visit, or talk the customer through SADP to read you the serial + Start Time, generate the code on the Quick Reset / Site Prep tab, and enter it in SADP on their LAN.

Reset code = serial + camera's own clock date. Prefer Hik-Connect or VPN for remote. Port-forwarding a camera to the internet is the most-attacked setup — harden it.
